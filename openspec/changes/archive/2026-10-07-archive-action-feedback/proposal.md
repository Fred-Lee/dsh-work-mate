# Make Long Panel Actions Visible

## Why

真机点击「完成归档」时**服务端几百毫秒就完成并落盘**，但面板只是把按钮置灰，**没有任何进行中提示、
没有完成反馈**——用户的原话是"点击到完成归档之后就没响应了"，后来才发现其实早就成功了。

一个"看起来卡死、其实成功"的操作，在真实使用里会让人反复点击、误判系统故障。

## What Changes

1. 主按钮进入 **pending 文案**：`推进中…` / `归档中…（编排在跑）`；
2. 成功后**在卡片上**显示结果行（`✅ 归档完成`；若编排报告 `forced: true` 则标注"force：已跳过审查门"）；
3. 失败时把服务端错误**同时**显示在卡片上（此前只有面板顶部一处，容易错过）；
4. 新增 `.wm-action-note` / `.error` 样式。

## Impact

- `src/client/App.tsx`（状态 + 三处按钮文案 + 卡片结果行）、`src/client/styles.ts` 样式。
- 纯客户端；服务端与既有行为零变化（该动作原本就会刷新列表与详情）。
