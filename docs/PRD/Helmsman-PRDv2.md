# 🚀 Helmsman 定位升级：从“Agent 调度器”到“AI 原生开发工作台”


## 一、新定位：Helmsman Workbench

**一句话定义**：
> Helmsman 是一个基于 DSH 的 **AI 原生开发工作台**，覆盖从“行业研究 → PRD 沉淀 → 任务拆解 → Agent 执行 → 知识库归因”的产品全生命周期。

**核心理念**：
> **对话驱动开发（Conversation-Driven Development）** —— 你通过自然语言与 Helmsman 对话，它帮你完成从想法到代码的全链条。

**现有 Helmsman 的角色**：
> 现有的 Agent 并行调度看板（Dashboard + Diff）将成为 Helmsman Workbench 的 **“执行层（Execution Layer）”** ，负责 PRD 拆解后的具体编码任务的并行执行和对比合并。


## 二、四大核心能力

| 层级 | 能力模块 | 对应你的需求 | 状态 |
|------|----------|-------------|------|
| **L1 研究层** | Deep Research + 行业信息沉淀 | 对话中 Deep Research 行业信息 | 🆕 需新增 |
| **L2 产品层** | PRD 生成 + 里程碑拆解 + 任务分解 | 沉淀 PRD → 拆解里程碑 → 具体任务 | 🆕 需新增 |
| **L3 执行层** | 多 Agent 并行调度 + Diff 对比合并 | 执行具体编码任务 | ✅ 已有（FEATURES.md） |
| **L4 知识层** | 接入 Tolaria + 项目知识图谱 | 知识库、图谱、基于现有项目分析 | 🆕 需新增 |


## 三、L1-L4 详细交互流程与 UI 设计

### 6.2 Tolaria 接入方式

Tolaria 是一个开源的知识库系统，支持 API 接入。`@helmsman/knowledge-tolaria` 插件负责：

1. **同步**：定时/按需将 Tolaria 中的项目文档、Wiki、设计稿同步到 Helmsman 知识图谱
2. **查询**：在 L1/L2 生成内容时，自动查询 Tolaria 中的相关知识，避免重复造轮子
3. **反馈**：将 L3 执行产生的代码变更、新的设计决策回写到 Tolaria

**Tolaria API 参考**：
```typescript
// Tolaria 知识库查询
const searchResult = await tolaria.search({
  query: "作业批改 OCR 实现方案",
  scope: "project:作业服务",
  limit: 10
});

// 返回: 相关文档片段 + 关联关系
```
